Digital Display

Standalone 24-hour clock

Use mode=digital for a pure digital clock, mode=swim for the original pace clock (the default), or mode=wall for the analog wall clock. The digital clock uses local system time in 24-hour format with leading zeros. It never displays analog hands, dial markings, a reference image, or a logo.

Open clock.html?mode=digital&setupmode=1 to configure it. The three clock buttons keep separate settings while the page is open. Use the source selector and “Grab values from other interface” to copy another clock’s settings. Only controls relevant to the selected mode are shown.

Design choices:

  • clean: solid, bold text.

  • segment: classic seven-segment LED digits.

  • matrix: the same dot patterns as the pace clock’s VFD.

  • outline: outlined text.

  • split-flap: text on individual dark cards with a horizontal flap seam. This is a static visual treatment, not a flip animation.

Font choices for Clean, Outline, and Split-flap:

  • mono: system monospace.

  • sans: Arial / Helvetica.

  • serif: Georgia / Times New Roman.

  • condensed: Impact / Arial Narrow.

  • rounded: Trebuchet MS / Verdana (default).

  • club: the bundled BFont.

System font availability varies by device; each choice has a fallback. No external font service is used. Fonts are fitted within fixed digit cells to keep the display stable as the time changes. Seven-segment and Dot-matrix use drawn shapes, so the font selector is disabled for those designs.

The Digit spacing (kerning) slider works in all five designs and adjusts the gaps only between adjacent digits within each HH, MM, or SS pair. It does not affect the gaps beside colons. Zero removes the extra gap, 1 preserves the original spacing, and 4 gives four times the extra gap. Negative values down to -4 pull character cells closer together and can overlap them. Spacing only moves characters: glyph size, height, and stroke thickness remain unchanged. Size is fitted using the original spacing, independently of this control. Wide spacing can extend beyond the drawing area; reduce Size to fit it. Spacing is retained when switching modes and included in shared URLs.

Colon spacing (digitalColonPaddingRel, default -0.39, range -2 to 4) adds equal padding on each side of each separator, independently of digit spacing. In digit-cell units, a gap between adjacent digits is 8 * digitalSpacingRel and a gap beside a colon is 8 * digitalColonPaddingRel. Negative colon spacing pulls separators closer to the neighboring digits and can overlap them. Neither slider affects the other type of gap. Unlike the Swim Clock’s additive VFD spacing, standalone digital spacing uses separate gaps for digits and colons. Use Colon vertical offset (digitalColonYOffsetRel, default 0, range -0.1 to 0.1) to move only the separators up (negative) or down (positive), relative to the 100-unit digit cell height. Both controls apply to every design and both separators when seconds are shown. They do not change glyph size or stroke thickness and are retained in mode settings and shared URLs.

Digital mode defaults to an edge margin (driftMarginRel) of -0.052 and the Wall Clock color palette, including cyan digits. These defaults apply only to the digital clock; Swim and Wall defaults are unchanged. Explicit URL parameters override them. clock.html?mode=digital loads this configuration.

Color presets, Run clock, screen-saver drift, debug overlay, and Copy URL work in digital mode too. Turn off Run clock to edit the manual preview time. At the original spacing, the display fits both the width and height of its drawing area. Drift bounds account for the actual character spacing, rectangular shape, vertical position, and glow. If the display is too wide to drift, it stays centered.

The generated share URL preserves the selected mode and its settings, but omits setupmode. vfdEnabled and the other VFD geometry/test settings below apply only to the swim clock’s optional display, not the standalone digital clock.
